# Airdrop Daily Tracker · ایردراپ‌ترکر

**A personal checklist and account organizer for airdrops you *already* farm.**
It does **not** find, list, or recommend airdrops, and it doesn't connect to any wallet or blockchain.

🔗 Live: https://ckercrypto.github.io/airdrop-tracker/

## What it does
- **One card per project** you're farming. Each card records which **wallet** (name or public address), **chain**, **X account**, **Discord account**, **browser/profile**, and email/Telegram you use for it, plus its link, status, priority, snapshot/TGE date, money spent, and notes.
- **Your own tasks** go in each project. You add them yourself (e.g. "faucet + swap", "daily check-in", "like & retweet"). Each one can be **daily**, **weekly**, or **one-time**, and can hold a link.
- **Checkboxes** you tick as you finish tasks. Daily checks reset every night, and weekly ones reset each week (the week starts on Saturday).
- **Progress**: today's overall progress, a progress bar for each project, a 🔥 streak, and a 14-day history.
- **Account map**: see which wallet, X, Discord, or browser profile is used by which projects.
- **Filters & search**: search by browser, wallet, or status, or show only what's unfinished today.
- **Backup / Restore** as a JSON file, which also moves your data between phone and PC.

## Privacy
- Everything is stored **only in your own browser** (localStorage). Nothing is uploaded and there's no server. Anyone else who opens this link sees their own empty app.
- **Never** enter seed phrases, private keys, or passwords. The app warns you if something looks like one.

## خلاصهٔ فارسی
یه دفترچهٔ شخصی برای ایردراپ‌هایی که خودت انجام می‌دی. **ایردراپ پیدا نمی‌کنه و به کیف پول وصل نمی‌شه.**
- برای هر پروژه ثبت می‌کنی کدوم کیف پول، اکانت X، دیسکورد و مرورگر بهش وصله.
- تسک‌های روزانه، هفتگی یا یک‌باره رو خودت اضافه می‌کنی و با تیک زدن جلو می‌ری.
- چک‌های روزانه هر شب ریست می‌شن.
- اطلاعات فقط توی مرورگر خودت ذخیره می‌شه.
